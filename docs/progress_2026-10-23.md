## 本轮代码变更

1. **接通通信观测。** 默认邻居输入由成功投递的状态快照产生，丢包、时延、
   数值噪声和消息过期直接影响策略输入。断链后保留未过期缓存，避免使用全局
   真值提前判定邻居失效；乱序旧包不能覆盖新包。显式 `oracle` 模式用于理想信息对照。
2. **实现可学习注意力。** 用自身及邻居编码、快照距离权重、消息年龄计算邻居
   权重；保留 `mean` 与 `none` 两种消融。空邻域输出零聚合，注意力掩码及反向传播
   已验证。旧均值检查点仍可加载；训练脚本默认 `attention`，模型构造函数默认 `mean`。
3. **补充故障与复现配置。** 训练入口支持通信扰动，并默认注入可恢复链路及
   节点故障。故障持续时间至少为一个仿真步，短回合也能经历节点缺失。
   训练种子传入环境，检查点记录下一回合种子；训练与评估保存各自配置。
4. **修复团队奖励记账。** 原先对执行动作的成员取步末奖励均值，节点恰在步末
   离线时，其奖励变零会稀释团队奖励。训练和评估现在直接使用环境计算的团队奖励。
5. **隔离通信随机流。** 状态广播与协议消息使用独立随机流，新增状态流量不再
   改变原有 gossip 的扰动采样；所有包仍经过同一拓扑校验、队列和过期规则。
6. **提供实验矩阵入口。** `scripts/run_ablation.py` 顺序执行三种聚合器、三个
   训练种子，每组独立保存模型和评估结果；支持只生成计划，拒绝覆盖已有训练输出。

## 实际验证

运行环境：Python 3.12.14、NumPy 2.3.5、PyTorch 2.14.1+cpu、Matplotlib 3.10.8。

| 检查 | 结果及范围 |
|---|---|
| 原版测试 | 86 项全部通过 |
| 更新后测试 | 108 项全部通过，新增 22 项 |
| 注意力训练 | 5 个智能体、2 次更新、每次 32 步，共 64 环境步；含丢包、时延、抖动、噪声及节点故障 |
| 均值与无邻居训练 | 各完成 1 次更新、16 环境步；仅验证对应训练入口 |
| 跨规模推理评估 | 注意力检查点在 5、10、20、50 个智能体上运行；三类场景、三种策略，共 36 个评估回合，使用配对种子且每回合重建环境 |
| 实验矩阵脚本 | 完整执行 1 个缩小训练组及其评估；另验证生成默认 9 组计划 |
| 补位演示 | seed=7、40 步下，原版及更新版均确认 1 个缺失任务、产生 1 次任务响应并恢复 1 条搜索带覆盖 |
| 语法及补丁检查 | compileall 与 git diff --check 通过 |

通信观测回归测试覆盖全丢包、延迟旧快照、噪声、缓存过期、传输中过期、乱序、
回合重置、协议收件箱分流、显式真值对照。学习测试覆盖排列不变性、空邻域有限
梯度、质量输入、填充掩码、旧检查点、种子传递和故障时团队奖励。

本轮曾观察到新增状态广播改变 gossip 的随机丢包序列，使固定种子补位演示失效。
隔离随机流后补位响应与覆盖恢复重新出现，并增加独立随机流回归测试。
更新后的总丢包统计包含状态包，因此无需与原版总丢包率逐字相同。

**这些结果仅证明工程链路可运行。** 64 步训练不足以获得成熟策略；36 个快速
评估回合的任务成功率均为 0，不能支持算法优于规则、鲁棒性或跨规模泛化结论。
均值和无邻居的训练预算也不同于注意力，本轮三次短训练不得作为算法对照结果。
原始配置、训练指标及 36 组评估汇总保存在 `validation_2026-10-23.json`。

## 尚未解决的研究问题

- 尚未建模信噪比，未实现在线丢包率估计或链路容量、带宽竞争与拥塞。
- 训练仍是固定规模和固定时刻的故障；尚未实现规模、故障节点和断链比例的训练随机化。
- 默认评估只包含一条指定链路故障，并不等于切断 30% 或 50% 实际可用链路。
- 全队目标发现比例仍作为共享任务输入；规则策略还读取成员索引和在线数量。
  因此不能声称已经实现完全局部信息的部署协议。
- 任务仍为二维静态目标搜索；复杂障碍、动态围捕、编队穿越、静态图消融、
  外部 MAPPO/QMIX/DCG 对照和实物迁移尚未完成。
- 规则补位与学习策略仍是独立策略，本轮没有证明学习策略学会了搜索带补位。
- 跨规模时场地、目标密度和通信半径会影响任务难度；正式泛化实验需明确保持
  哪些量不变，并报告变化，避免把增加节点带来的覆盖率提升误作算法泛化优势。
