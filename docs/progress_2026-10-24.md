# 2026-10-24 实验汇总与安全续跑记录

## 本轮范围

在现有 Graph-MAPPO、通信观测和规则补位策略上完善实验工作流，保持策略接口、
损失函数、故障机制和原始评价指标不变。没有新增安装依赖，没有删除原始实验数据。

### 多种子消融汇总

- `evaluation/ablation.py` 读取实验计划、实际训练配置、训练日志、场景配置及逐回合结果。
- 对缺失训练组、重复回合、配置不一致、预算不足、非有限指标及必填空值明确报错。
- 先在每个训练种子内部汇总评估回合，再对种子等权计算均值和样本标准差。
- 不足两个有效种子时标准差为空；未发生的恢复等事件不补成零秒。
- 同一配对测试任务的规则基线核对一致后去重，不当成多个独立训练种子。
- 支持实验结束后自动汇总，以及 `scripts/summarize_ablation.py` 单独汇总已有结果。

### 训练/评估阶段级续跑

- `scripts/run_ablation.py --resume` 核对原计划，校验日志、模型检查点与评估回合。
- 完成阶段直接复用；不完整阶段原样移入 `attempts/` 后重新运行，不覆盖原文件。
- 训练重跑时，对应旧评估也归档，避免把旧模型的评估混到新训练中。
- 汇总复用前核对 JSON、CSV 内容和 PNG 完整性；截断文件归档后重建。
- 事件日志追加记录阶段过程，操作系统文件锁阻止同目录的实验入口同时写入。
- 原计划只用于读取配置，执行命令由当前项目重新构建，支持完整实验目录迁移。

这里不恢复单次训练中断瞬间的 PPO 轨迹、环境或随机数状态。没有完整保存训练
日志和检查点的训练组会重新训练，不能把阶段级续跑描述为精确断点恢复。

|---|---|
| 完整测试 | 138 项通过：原有 111 项、16 项汇总测试、11 项续跑测试 |
| 缩小实验矩阵 | none、mean、attention 各运行训练种子 0/1/2，共 9 组 |
| 训练预算 | 每组 1 次更新、8 个环境步，共 72 个环境步 |
| 独立评估 | 3/5 智能体、3 类场景、3 种策略，共 162 个回合 |

| 独立汇总复核 | 自动与独立入口产生的 CSV、JSON 内容一致 |
| 已有矩阵续跑 | 9 个训练阶段及 9 个评估阶段全部复用，91 个原计划和结果文件哈希不变 |
| 故障恢复测试 | 临时测试目录中的损坏检查点、不完整评估、截断 CSV/PNG 均能归档并重建 |
| 补位演示 | 40 步确认 1 个缺失任务，产生 1 次响应并恢复 1 条搜索带覆盖 |

缩小实验的全部回合成功率为 0；每组仅训练 8 步，只能证明工程流程可运行，
不能作为收敛、鲁棒性、跨规模泛化优势或三种聚合器优劣的证据。
损坏和中断输入只在临时测试副本中构造；已有科研实验文件未被截断或删除。
本地验证产物位于 `outputs/ablation_summary_validation_20261024/`，由 `.gitignore` 排除。

## 运行方式

完整回归：

```powershell
python -m unittest discover -s tests -v
```

使用新输出目录复现缩小矩阵；保留参数数组，可直接进行原配置续跑：

```powershell
$smokeArgs = @('--aggregations', 'none,mean,attention', '--seeds', '0,1,2',
    '--train-agents', '3', '--agent-counts', '3,5', '--updates', '1',
    '--rollout-steps', '8', '--update-epochs', '1', '--max-steps', '12',
    '--hidden-dim', '8', '--episodes', '1', '--output-dir', 'outputs/ablation_workflow_smoke')
python scripts/run_ablation.py @smokeArgs
python scripts/run_ablation.py @smokeArgs --resume --dry-run
python scripts/run_ablation.py @smokeArgs --resume
```
