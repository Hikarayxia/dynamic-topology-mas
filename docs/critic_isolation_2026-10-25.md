# 2026-10-25：价值梯度隔离试训

## 起点与目标

PR #2 已于 2026-10-24 合并。读取最新主分支 c8626ed 及前一轮训练记录后，
本轮针对共享编码器的价值梯度干扰进行单变量对照，没有继续重复工程冒烟训练。
前一轮 Huber 对照有改善，但其独立评估中学习策略的任务成功率仍为零。

新增可选 `critic_encoder_mode=detached`，默认 `shared` 保留旧行为。
Critic 计算形式为 `V = critic(mean(stop_gradient(encoder(obs))))`。
该模式下价值损失对编码器的直接梯度为零，Actor 到编码器、Critic 到价值头的
梯度保留；同一权重的前向结果完全相同，网络结构、参数量、观测和奖励不变。

这不是完全独立的 Actor/Critic 网络：价值仍参与 GAE，Actor 更新仍改变 Critic
输入表示，全局梯度裁剪也仍有共同影响。因此只把它解释为一个梯度路径消融。

## 固定协议

- 基于 c8626ed，训练种子均为 0，模型由相同的初始化过程生成。
- 4 个智能体，50×50 地图，6 个未知目标，dt=0.2，最长 300 步。
- attention，hidden_dim=64，Huber 价值损失；100 次更新、256 步采样、4 轮 PPO。
- 每组实际完成 25,600 环境步；训练配置去掉输出路径和梯度模式后完全一致。
- 训练使用原理想通信配置及可恢复链路/节点故障，与本轮共享模式对照保持一致。
- 两组独立评估使用配对种子 40000–40019，每场景每策略 20 回合。
- 场景为正常、链路/节点故障、通信扰动；通信扰动为丢包 0.3、延迟 0.2、
  抖动 0.1、噪声标准差 0.01；其余两组仍为理想通信。
- 共执行 360 个评估回合。重复规则基线逐回合核对一致后去重，剩余 240 条
  模型/策略-场景-测试种子记录，不能把它们解释为独立训练种子。

两份模型都在当前环境重新训练，未借用或覆盖昨天的模型与原始实验目录。
种子相同用于配对控制，不能据此声称与昨天不同运行环境的模型逐字节一致。

## 实际结果

下表均为学习策略，箭头为 shared → detached，每场景 20 个回合：

| 场景 | 任务成功数 | 平均目标发现率 | 平均累计奖励 | 平均碰撞计数 |
|---|---:|---:|---:|---:|
| 正常 | 0/20 → 2/20 | 33.33% → 56.67% | -7.935 → 15.667 | 13.50 → 0.15 |
| 链路/节点故障 | 0/20 → 2/20 | 33.33% → 57.50% | -11.364 → 15.369 | 16.15 → 0.40 |
| 通信扰动 | 0/20 → 1/20 | 33.33% → 49.17% | -7.921 → 11.169 | 13.50 → 0.30 |

同批测试的规则搜索成功数为 11/20、8/20、11/20，规则补位为 6/20、6/20、6/20。
隔离模式仍明显落后于规则搜索，并未解决协同覆盖或任务完成问题。
碰撞数是逐时间步接近的智能体对的累计计数，持续接近会重复计数，不是独立事故数。

这里只含一个训练种子，不报告跨训练种子标准差、显著性或跨规模泛化优势。
测试种子虽未用于梯度更新，但本次分析后已经被查看，不应再当作后续调参的
全新盲测集。观察到局部改善不代表任何安全保证，不足以把默认模式改为 detached。

## 代码、测试与兼容性

- 训练配置和两个 CLI 增加梯度模式；模式写入 run_config 和检查点。
- 恢复前核对模式，错误模式在模型和优化器变更前拒绝；旧缺失字段按 shared。
- 默认 shared 不向矩阵计划加入新参数，保持旧计划续跑；统计签名规范化缺省值，
  避免旧完成组与新 shared 组被误判为不同实验协议。
- 新增 8 项测试：前向不变、价值梯度阻断、Actor 梯度保留、价值单独更新不改变
  动作、真实 PPO、CLI/计划、旧检查点及配置兼容性。
- 小型隔离矩阵实际运行两个训练种子，并完成汇总和全部阶段复用。
- 完整回归 176 项通过（原 168 项加新 8 项）；耗时 54.875 秒。
- 回归中发现原无邻居测试使用逐位相等。100 个初始化的复核中，64 个存在舍入
  差异，最大仅 5.960464477539063e-08。改用 float32 合理容差，未修改该模式算法。

## 原始产物与复现

`outputs/critic_isolation_20261025/` 保存两组完整训练、检查点、逐回合评估、
场景配置、来源指纹、图表及矩阵验证产物。模型与原始结果仍由 gitignore 排除。
交付包包含这些原始产物、只读复核脚本 analyze_results.py、comparison.json 和
本轮代码补丁；没有删除或覆盖既有实验。
复核脚本检查训练预算、除模式外的配置一致性、评估种子/回合完整性、模型有限性、
执行时检查点和结果指纹、配对场景、重复规则基线，随后汇总实际回合。
指纹检测误配和意外更改，不是防恶意篡改的数字签名。

在新输出目录复现两种模式（分别替换 shared/detached 和输出路径）：

```powershell
$env:OMP_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
python scripts/train_mappo.py --updates 100 --rollout-steps 256 --update-epochs 4 --agents 4 --max-steps 300 --hidden-dim 64 --seed 0 --aggregation attention --value-loss-type huber --critic-encoder-mode detached --output-dir outputs/isolation_reproduction/detached/training
python scripts/evaluate_policies.py --episodes 20 --agent-counts 4 --max-steps 300 --seed 40000 --checkpoint outputs/isolation_reproduction/detached/training/mappo_checkpoint.pt --packet-loss-rate 0.3 --base-delay 0.2 --delay-jitter 0.1 --noise-std 0.01 --output-dir outputs/isolation_reproduction/detached/evaluation
```
